# 秒点规划器（miaodian-guihuaqi）

一个给「秒哒」平台多账号玩家用的本地规划工具。把每个号当前有多少秒点填进去，它按秒点规则算出：接下来每天该登录哪个号、点赞几次、哪个号复制大号的哪个作品、大号什么时候余额够打包。

> 当前版本：**v1.13.0** · 仓库公开（源码与构建脚本一并开源，可自由学习、修改、分发）

账号数据只保存在本机，**不会上传**；只有检查更新时会访问 GitHub 读取版本清单。

## 它能做什么

- 自定义小号数量、备注、当前秒点、本月已领登录天数（大号也有）。
- 按真实日历日从今天（或明天）排到月末；自动识别当月天数与周日。
- 周日按休息日处理：零收入、后端照扣，方案自动跳过。
- 作品按 1→2→3→4 轮换复制，同一个号不会连续复制同一个作品。
- 按先进先出模拟 7 天有效期（默认 7 天，可在参数里调整），定价设太高会自动反映过期浪费；每笔获得的秒点标注过期日期，今日面板对「今天/明天到期」红字预警。
- 打包完全手动：勾选才在起始日扣一次，平时只提示「可打包时机」。
- 逐日行动预览：每天每个号做什么，一眼看清；点「生成方案」后在**独立窗口的单一页面**完整显示方案，不再拆分页签，支持复制全文与导出 CSV。
- 确认采用后，主页面「今日执行」面板会**每天自动更新**，直接显示当天每个号该做什么，不用再翻方案；想看完整方案点「查看当前方案」随时回看，不必重新生成。
- 各号「当前秒点」也会**按方案自动扣/加并随日期推进**；中途手改过的余额会保留，后续增量继续叠加。
- 「一眼速览」自动摊在主页面：今日净变动、7天内到期、打包机会/差额、负余额、方案进度，不用点按钮就能看到。
- 「一键生成并采用」最少操作：一次点击即可生成并采用，想看细项再点「查看当前方案 / 查看加减明细」，都无需重新生成。
- 「查看加减明细」四段式核对：①当前各号秒点 ②方案预期 vs 当前（解释为何不一致）③逐笔「上笔→变动→本笔」核对（可切换按日期/按账号、只看已发生/全部）④软件实际加减记录。
- 导出明细 CSV（Excel 可打开）；配置自动记忆——改了就存到用户目录，exe 换位置或更新后数据仍在，不用每次重填。

## 内置「版本更新」

- 顶部常驻版本号 +「检查更新」按钮；**每次启动后台静默检查**。
- 发现新版用**非模态横幅**提示（立即更新 / 跳过此版本 / 稍后再说），不打断使用。
- 下载支持多镜像、断点续传、分段并发，并做 **MZ 头 / 文件大小 / SHA256** 三重校验。
- 安装时原地替换正在运行的 exe（失败必还原、绝不退出），装完问「立即重启 / 稍后重启」。
- 清单地址多镜像并发取最高版本，不使用 jsDelivr（避免锁旧 commit 误报已是最新）。

## 运行方式

### 普通用户（推荐）

1. 下载 **[⬇ 秒点规划器.exe](https://github.com/H-ZHOWEI/miaodian-guihuaqi/raw/main/dist/%E7%A7%92%E7%82%B9%E8%A7%84%E5%88%92%E5%99%A8.exe)**
   （也可以在仓库里点开 `dist/秒点规划器.exe`，再点右上角「Download raw file」下载）。
2. 放到任意文件夹（例如 `D:\秒点规划器\`），**双击即可打开**，无需安装 Python 或运行库。
3. 首次运行 Windows 可能提示「已保护你的电脑」：点 **更多信息 → 仍要运行** 即可（个人编写、未购买数字签名，属正常现象）。

详细说明见 **[操作说明.md](操作说明.md)**。

### 开发者

用带 tkinter 的 Python 3.12 启动：

```bash
py 秒点规划器.py
```

重新打包：双击 `build.bat`（或手动运行其中的 PyInstaller 命令）。

## 仓库结构

```
秒点规划器.py        # 全部源码（单文件，含更新模块）
dist/秒点规划器.exe  # 打包好的独立 exe
version.json         # 版本清单（内置更新读取）
build.bat            # 一键打包脚本
README.md            # 本文件
操作说明.md          # 面向零基础用户的完整操作说明
CHANGELOG.md         # 版本记录
```

> 运行时生成的 `秒点规划器配置.json`、`update_config.json` 属于个人数据，**不上传仓库**。

## 发版流程（开发者）

1. 改代码、升版本号（小改第三位、大改第二位）。
2. 同步更新 `CHANGELOG.md` / `操作说明.md` / `README.md` / `version.json`。
3. 跑 `build.bat` 重新打包。
4. 计算 `dist/秒点规划器.exe` 的 SHA256 与大小，写回 `version.json`。
5. 提交并推送到 `main`。
6. 远端校验：`git ls-remote`、`git show origin/main:version.json`、`git cat-file -s`。
